### Mandatory completeness corrections for 010-H

010-G found four material own-purpose gaps that must be corrected during canonical re-specification:

- **Evaluation Obligation** — add a successor-responsibility path when a previously satisfied obligation must be replaced for legitimate re-evaluation while preserving the historical satisfaction;
- **Rubric** — expose response interpretation/validation queries so valid-judgment semantics are owned by Rubric rather than implicitly delegated to Scorecard;
- **Versioning** — expose explicit invalidation/current-eligibility behavior consistent with the existing rule that invalidation may leave no current eligible Version and never silently revives a predecessor;
- **Export** — expose explicit representation-currency transitions/queries for Affected/Stale/Superseded/Retired semantics already owned by Export.

### Boundary genericity corrections for 010-H

010-G also found that much current direct peer typing is application composition rather than intrinsic Concept semantics. The eventual specifications should use abstract parameters where only identity/content/context is needed, including:

- Division over `Scope`/`Member` rather than Competition/Team internals;
- Panel over `Scope`/`Member` rather than Participation internals;
- Evaluation Occurrence over abstract Subject/Evaluator/PresentedContext/Basis;
- Evaluation Obligation over abstract Evaluator/Subject/Basis/Scope/Evidence;
- Scorecard over abstract Evaluator/OccurrenceContext/EvaluationBasis;
- Participation over Participant/Scope/Capacity;
- Access over Principal/Capability/Resource/ContextFacts/Rule;
- Provenance over Subject/StateRef/Actor/RepresentedAuthority/Scope/Source;
- Outcome Declaration over Scope/OutcomeBasis/DeclaringAuthority;
- Export over SourceBasis/representation/audience profiles;
- Publication over an abstract Representation/Audience/Channel/PublishingAuthority.

These are conceptual parameters, not programming generics or implementation types.

### Synchronization and inclusion remain later work

010-G deliberately does not absorb different-purpose behavior merely to make Concepts look complete. Occurrence → obligation creation, Scorecard → obligation satisfaction, lifecycle → Access expiry, source correction → declaration/export currency, and Competition Finalization ↔ Outcome Declaration remain Phase 011 composition questions.

Likewise, questions such as whether Publication requires Export in every product variant, whether Panel is optional, or whether Division/Award can be omitted belong to Phase 012 product-family/inclusion dependence.
