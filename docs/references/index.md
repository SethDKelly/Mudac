# External Authorities and References

This directory uses the OKF `references/` convention for external methodologies, standards, specifications, and other resources that MUDAC adopts, profiles, or depends upon.

Reference documents identify the external authority/version where material, why MUDAC uses it, the MUDAC-specific adoption/profile, and important non-adopted boundaries. They link/pin external sources rather than copying full specifications into this repository.

# Current references

* [Open Knowledge Format v0.2](open-knowledge-format.md) - pinned OKF specification reference and MUDAC adoption boundary for bundle structure, provenance, trust, lifecycle, freshness, and actor conventions.

# Expected later references

* Daniel Jackson Concept Design
* WCAG 2.2
* future AWS, security, and platform standards where materially adopted

A newer external release does not silently change a MUDAC adoption profile. Adoption/version changes occur through explicit review and canonical governance.
