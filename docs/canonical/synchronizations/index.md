# Cross-Concept Synchronizations

Current canonical contracts for how independent MUDAC Concepts and derived mechanisms coordinate without collapsing ownership or transferring semantic authority.

* [Concept Synchronization Contracts](concept-synchronizations.md) — trigger, authority, preconditions, postconditions, temporal/history effects, failure/retry semantics, and authority seams for the current cross-concept model.

Synchronizations are not additional MUDAC Concepts. They coordinate accepted Concept actions and derived/policy consequences while preserving each owner's state and authority.

The current synchronization audit and rationale are recorded in [007-C — Cross-Concept Synchronization Completeness, Trigger, Preconditions/Postconditions & Authority-Seam Audit](../../007-design-refinement/007-C-cross-concept-synchronization-completeness-authority-seam-audit.md).
