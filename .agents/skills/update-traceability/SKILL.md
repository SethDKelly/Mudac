# Update traceability

## Human-directed boundary

This workflow is **A2 supporting work** only when the human-selected task already requires a change whose repository references must remain accurate.

## Workflow

1. Identify the primary changed authority/artifact and why traceability must change.
2. Update only directly affected registry links, generated inventories, indexes, status mirrors, source lineage or acceptance references.
3. Preserve stable IDs for compatible moves/clarifications; use canonical change governance for incompatible semantic replacement.
4. Regenerate derived routing/index artifacts from their declared sources rather than hand-editing generated files.
5. Run the relevant knowledge/reference validation.
6. Confirm that no routing artifact became a competing semantic owner.

## Stop conditions

Do not use traceability work to introduce new semantics, adopt candidate architecture, start adjacent work, or rewrite unrelated historical evidence.
