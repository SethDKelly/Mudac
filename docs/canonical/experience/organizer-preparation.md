# Canonical contract

Preparation spans Competition details, Divisions, Teams/attributes, Aliases, Rubric, Evaluation Policy, Awards, expected Judges/Panel planning, and materials.

The workflow is non-linear: Organizers may work in the order the event requires. A readiness workspace composes those sources and distinguishes blocking configuration conditions from operational warnings.

`Competition Ready` is derived from valid source configuration and explicit Organizer lifecycle commitment. Final day-of-event Panel staffing and optional materials are not universal structural gates.

Readiness-invalidating changes return Ready to Draft rather than leaving stale Ready state.

Judge-safe preview should expose the actual blinded representation without granting Judge authority.
