# Canonical contract

Workflow/lifecycle, authority/persistence confidence, readiness, validity/eligibility, version/freshness, issue severity, disclosure posture, and publication state are independent dimensions. One generic badge must not collapse them.

Ambiguous finality words are qualified by subject: `Draft complete ≠ Scorecard Finalized`, `Encounter Complete ≠ Event Completed`, `Ranking Ready ≠ Official`, `Competition Finalized ≠ Published`, and `Acknowledged ≠ Resolved`.

High-consequence success must be durably confirmed; transient optimistic feedback cannot invent authority. Confirmation friction scales with consequence and uses semantic corrective verbs rather than vague destructive labels.

Recovery states the attempted action, definitely known state, uncertainty, preserved work, safest next action, and escalation path. Stale state cannot silently overwrite newer authority.
