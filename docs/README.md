## Authority model

Daniel Jackson Concept Design remains the methodology used to determine MUDAC product meaning. OKF is the knowledge representation/navigation convention and does not redefine the accepted Concept catalog or application semantics.

Canonical current knowledge constrains later architecture/implementation. Historical phase records preserve rationale and lineage. Downstream implementation documentation cannot override a canonical product rule by restating it differently.
