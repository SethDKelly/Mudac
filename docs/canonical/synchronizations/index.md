## Current interpretation rules

- Identity continuity is not Participation authority.
- Participation capacity is not Access permission.
- Panel membership ≠ occurrence participation ≠ responsibility ≠ Scorecard evidence.
- Evaluation Basis is one exact authoritative Rubric Version.
- one Evaluation Obligation maps to at most one logical Scorecard.
- Scorecard Draft state is non-authoritative.
- supersession ≠ invalidation ≠ replacement.
- historical obligation satisfaction != current evidence eligibility.
- factual Coverage != exception disposition; `Incomplete + accepted exception` may both be true.
- missing evidence is never converted to zero.
- Aggregate existence != Coverage satisfaction != rank eligibility.
- Rank consumes a supplied rank-eligible Team set and declared policy; it is not edited directly.
- calculated Rank != official result authority.
- Rank-derived Award selection basis does not transfer Award conferral authority.
- Rank recalculation never silently moves an existing Award.
- ordinary MUDAC closeout coordinates Competition Finalization with explicit initial Outcome Declaration while preserving independent ownership.
- Competition Finalized != Outcome Declaration content/history.
- calculated != official != public.
- post-Finalization correction never rolls Competition backward.
- a materially affected current declaration becomes `Affected` but remains latest declared official authority until explicit successor confirmation.
- corrected calculations/Awards do not silently create a successor declaration.
- affected-state propagation is dependency-specific and owner-specific; it does not silently change Export or Publication authority.
- **Judging Encounter** and **Official Outcome Revision** references elsewhere remain historical adapters/evidence only.
- runtime retry/idempotency/transaction/queue/session/transport language in old documents is not current Concept Design authority.
