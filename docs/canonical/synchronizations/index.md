## Current interpretation rules

- Identity continuity is not Participation authority.
- Participation capacity is not Access permission.
- Access permission is not semantic authorship.
- Readiness is derived and cannot write Competition lifecycle.
- `completeEvent` may coexist with Outstanding Evaluation Obligations.
- Panel membership ≠ occurrence participation ≠ responsibility ≠ Scorecard evidence.
- `EvaluationOccurrence.prepare` creates no obligations; ordinary initial obligations arise at begin.
- `completeOccurrence` ends the occurrence, not responsibility.
- current Team/Division/Alias changes never silently rewrite historical occurrence presentation.
- Evaluation Basis is one exact authoritative Rubric Version.
- Rubric Version supersession never silently rebinds existing evaluation state.
- one Evaluation Obligation maps to at most one logical Scorecard.
- Scorecard Draft state is non-authoritative.
- initial Finalization establishes Scorecard authority + Version + Provenance + obligation satisfaction coherently.
- a Satisfied obligation refers to logical Scorecard identity; Versioning identifies the current authoritative snapshot.
- semantic amendment/capture correction successor states preserve one logical evaluation weight.
- Versioning/Provenance generic actions remain composition-only.
- paper/electronic/assisted capture preserve Judge author, basis, logical Scorecard and weight.
- Organizer capture/correction actor may differ from Judge represented authority but cannot invent judgment.
- **supersession ≠ invalidation ≠ replacement**.
- invalidation never silently revives an older Version or creates a successor.
- Evaluation Occurrence invalidation preserves occurrence and Judge-authored evidence history while current eligibility may be lost through the invalid dependency.
- Satisfied Evaluation Obligations never reopen; legitimate re-evaluation uses successor responsibility and a new logical Scorecard.
- Outstanding obligations tied to invalid context are explicitly ended rather than left satisfiable against it.
- replacement occurrences never clone participants, obligations or Scorecards automatically.
- post-authority capture correction stays on the same logical Scorecard only when structural identity is unchanged and source proof is unambiguous.
- wrong Evaluator/Subject/OccurrenceContext/EvaluationBasis is structural correction, not ordinary amendment.
- corrected historical assertions preserve both as-recorded/as-known and later best-known truth through Provenance.
- affected-state propagation is dependency-specific and owner-specific; it does not silently change Award, Outcome Declaration, Export or Publication authority.
- **Judging Encounter** and **Official Outcome Revision** references elsewhere remain historical adapters/evidence only.
- runtime retry/idempotency/transaction/queue/session/transport language in old documents is not current Concept Design authority.
