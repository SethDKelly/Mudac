## Governing distinction

```text
intrinsic Concept dependence
  = upstream Concept-boundary defect

synchronization / composition
  = how already-included Concepts interact

extrinsic inclusion dependence
  = including A requires B for A's intended MUDAC role

capability-conditioned co-inclusion
  = a named capability requires a Concept set
    without making each Concept universally depend on that set

product-family scope
  = which coherent capabilities/subsets are actually adopted

implementation dependency
  = out of scope
```

## 012-I scope decision

Current MUDAC product scope adopts one primary product/application variant:

> **PF-01 — MUDAC Live Competition Judging & Official Outcome**

PF-01 keeps all eighteen current Concepts in the supported capability envelope because the current mandate spans preparation, blinded live judging, operational coordination, authoritative/correctable evidence, official outcome formation, optional recognition and controlled externalization/release.

This does **not** mean every Competition actively uses every Concept.

In-scope profiles inside PF-01 include:

- official outcome with no Award;
- official-but-non-public state;
- Export prepared without Publication;
- controlled public non-official material;
- public official-result release;
- exceptional/no-result official disposition with an accepted reconstructible basis;
- paper/electronic/mixed continuity.

These are configuration/lifecycle/channel profiles, not separate products.

## Coherent contractions not adopted

Current coherent-but-unadopted or deferred contractions include:

- truly no-Division product;
- no-Panel product;
- occurrence-only or obligation-only standalone product;
- working Scorecard-only standalone product;
- completed judging-only product without Outcome Declaration;
- recognition-only final product;
- intentionally non-blinded competitive judging;
- no-Division rank-derived recognition.

Authoritative evaluation without Versioning/Provenance remains invalid under current authority semantics rather than a scope candidate.

## Composition revalidation result

**No immediate Phase-011 reopening is required for PF-01.**

Phase 011 already synchronizes the complete eighteen-Concept family selected as the current product variant and already supports Award optionality, official/non-public separation, Export without Publication, controlled release, exception-aware closeout, correction, and paper/electronic parity.

Deferred contractions carry explicit future revalidation routes rather than inheriting full-product composition silently.
