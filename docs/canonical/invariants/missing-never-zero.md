# Invariant

Missing evaluation is absence of evidence, not a Judge judgment of zero.

Coverage shortfall remains visible as shortfall; an accepted exception may permit proceeding but cannot fabricate evidence. Aggregate calculations include only eligible authoritative evaluations according to policy.

The same distinction applies to Criterion values where missing, zero, and not-applicable have different meanings.

See [Coverage](../mechanisms/coverage.md) and [Aggregate](../mechanisms/aggregate.md).
