## Current interpretation rules

- Identity continuity is not Participation authority.
- Participation capacity is not Access permission.
- Access permission is not semantic authorship or decision authority.
- Readiness is derived and cannot write Competition lifecycle.
- `completeEvent` can coexist with Outstanding Evaluation Obligations.
- Panel membership is intended grouping, not actual Evaluation Occurrence participation.
- actual occurrence participation is not Evaluation Obligation responsibility.
- `EvaluationOccurrence.prepare` creates no obligations.
- ordinary initial obligations are established at occurrence begin for the confirmed starting evaluator set.
- absent nominal Panel members therefore do not create phantom obligations.
- participant adjustment requires an explicit separate responsibility disposition; leaving the occurrence may still leave an obligation Outstanding.
- Panel changes never rewrite an already-begun occurrence.
- `completeOccurrence` means the bounded occurrence ended; it does not wait for or resolve obligations.
- current Team/Division/Alias changes never silently rewrite historical occurrence presentation.
- **Judging Encounter** references elsewhere are historical pre-split evidence and must be interpreted through Evaluation Occurrence + Evaluation Obligation.
- **Official Outcome Revision** references remain historical evidence for Outcome Declaration.
- generic Versioning/Provenance/Access-check/obligation-satisfaction actions are not automatically direct MUDAC actions.
- runtime retry/idempotency/transaction/queue/session/transport language in old documents is not current Concept Design authority.
