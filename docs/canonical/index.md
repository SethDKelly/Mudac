# Canonical MUDAC Knowledge

Phase 004 migration is in progress. A category index may be present before its canonical documents have been extracted and reviewed.

# Domain Meaning

* [Concepts](concepts/) - Current definitions of accepted MUDAC Concepts.
* [Mechanisms](mechanisms/) - Important derived or subordinate constructs that deserve first-class retrieval without becoming MUDAC Concepts.
* [Policies](policies/) - Governing/configurable competition semantics.
* [Invariants](invariants/) - Cross-cutting normative constraints with stable ownership.

# Experience

* [Experience](experience/) - Current conceptual UX contracts for Judge, Organizer, paper, accessibility, disclosure, and recovery behavior.

# Architecture

* [Architecture](architecture/) - Accepted system/application architecture contracts and decisions. This region is intentionally sparse until the later architecture phase.
