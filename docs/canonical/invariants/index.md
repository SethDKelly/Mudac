# Invariants

This directory will contain cross-cutting normative constraints that merit independent stable ownership and repeated downstream reference.

Canonical extraction is pending 004-C; stable rule-ID conventions are finalized in 004-E.

Expected subjects may include:

* Judge independence
* one logical Scorecard per Judge × Encounter
* missing evaluation is never zero
* Organizer authority does not become Judge authorship
* calculated is not official
* Competition Finalized is not automatically Published
* accessibility changes representation, not authority
* connectivity uncertainty never becomes false authoritative success

Not every normative sentence should become a standalone invariant document; dedicated ownership is reserved for constraints that are cross-cutting, repeatedly depended upon, and materially useful for audit/architecture/test reference.
