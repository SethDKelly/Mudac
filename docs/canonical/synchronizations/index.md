## Current interpretation rules

- Identity continuity is not Participation authority.
- Participation capacity is not Access permission.
- Access permission is not semantic authorship or decision authority.
- Readiness is derived and cannot write Competition lifecycle.
- a blocking source change while Competition is Ready returns it to Draft; Active history is never rolled back merely because readiness later degrades;
- `completeEvent` completes active live Judge Participations but does not satisfy/erase Evaluation Obligations;
- ordinary Judge private-evaluation Access closes from current Event Completed/Participation context without requiring a persisted ordinary Access-expiry action;
- `resumeEvent` restores no Judge Participation, Panel, occurrence/obligation state or Access automatically;
- every protected operation uses one explicit Participation context and never unions capabilities across roles;
- current Team/Division/Alias correction cannot rewrite historical judging presentation;
- **Judging Encounter** references elsewhere remain historical pre-split evidence and must be reconsidered across Evaluation Occurrence + Evaluation Obligation;
- **Official Outcome Revision** references remain historical evidence for Outcome Declaration;
- generic Versioning/Provenance/Access-check/obligation-satisfaction actions are not automatically direct MUDAC actions;
- runtime retry/idempotency/transaction/queue/session/transport language in old documents is not current Concept Design authority.
