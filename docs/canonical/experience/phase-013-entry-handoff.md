# Explanation obligations

## Context / scope

Where ambiguity would change meaning, make enough of the following understandable:

```text
Competition
actor / Participation context
Team subject
applicable Division / Alias disclosure context
```

## Evaluation work

Before authoritative judgment commitment, the Judge must be able to understand the relevant:

```text
Evaluation Occurrence context
Evaluation Obligation responsibility where applicable
Rubric / Evaluation Basis
Judge-facing Team context
```

## Working versus authoritative evaluation

Preserve:

```text
Draft / preserved work
  != authoritative Scorecard evidence
```

Expose Version/Provenance meaning where currentness, authorship or correction requires it.

## Evidence / derivation

Preserve:

```text
eligible authoritative evidence
  → Coverage / Aggregate
  → rank eligibility / Rank
```

without turning derived state into editable source truth.

## Recognition / official authority

Preserve:

```text
calculated != recognized != official
```

## Externalization

Preserve:

```text
source authority/currentness
  != Export representation/currentness
  != Publication release state
  != transport/delivery realization
```

## Temporal/correction semantics

Mappings must distinguish current, historical, invalidated, superseded, affected/stale, replacement and successor meanings when those distinctions change decisions or available actions.

# Application-action surface rule

Phase 013 maps the **application action surface established in Phase 011**, not an arbitrary union of Concept actions.

```text
D — direct application action
C — coordinated application action
P — composition-only participant
S — system-triggered conceptual reaction
X — intentionally unavailable generic application action
```

A mapping must not expose `P` or `X` behavior as a generic user action merely because the underlying Concept has an intrinsic action.

# Actor / affected-party perspectives

Phase 013 must account for, where relevant:

- Judge;
- Organizer;
- technical administrator/support operator;
- Student Team as materially affected non-user;
- external recipient of deliberately released material.

One generic user perspective is insufficient where authority, disclosure, authorship or affected-party meaning differs.
