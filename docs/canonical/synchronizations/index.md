## Interpretation boundary

Synchronizations explain how independently owned Concepts react and compose. They do not create a generic Workflow/Task/Coordinator owner.

Preserve key separations such as:

```text
Identity != Participation != Access
Evaluation Occurrence != Evaluation Obligation != Scorecard
Coverage != Aggregate != Rank
Rank != Award
Competition Finalization != Outcome Declaration
Outcome Declaration != Export != Publication != possession
```

Automation may execute already-authorized bounded consequences; it may not manufacture semantic authority.
