# Execute selected task

## Human-directed boundary

This workflow is **A2** for the explicitly selected task. It never grants A3 or A4 authority.

## Workflow

1. Restate the selected task boundary internally: objective, active phase/package, owned artifacts, necessary supporting edits, evidence, exclusions.
2. Resolve the current owners/stable rules that constrain the work before changing files.
3. If the task is domain implementation, confirm an active accepted implementation package and explicit execution authorization. If absent, stop.
4. Make only directly necessary and proportional changes.
5. Update directly impacted routing, generated indexes, status, references or traceability when omission would leave the selected task inconsistent or misleading.
6. Run the lowest-cost relevant safe validation.
7. Treat failures as evidence; do not weaken canonical requirements to obtain a pass.
8. Report completion evidence, residual risk and next eligible work without starting it.

## Stop conditions

Stop before external/destructive/scope-expanding A3 actions or semantic/accepted-architecture A4 changes unless separately authorized. Stop at the selected task boundary.
