# External Authorities and References

This directory uses the OKF `references/` convention for external methodologies, standards, specifications, and other resources that MUDAC adopts, profiles, or depends upon.

Phase 004 will add concise MUDAC reference documents rather than copying entire external specifications into the repository.

Expected subjects include:

* Open Knowledge Format (OKF)
* Daniel Jackson Concept Design
* WCAG 2.2
* future AWS, security, and platform standards where materially adopted

A reference document should identify the external authority, version/date where material, why MUDAC uses it, MUDAC-specific adoption/profile choices, and important non-adopted boundaries.
