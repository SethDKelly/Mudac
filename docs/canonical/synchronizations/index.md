## Current interpretation rules

- Identity continuity is not Participation authority.
- Participation capacity is not Access permission.
- Access permission is not semantic authorship or decision authority.
- Readiness is derived and cannot write Competition lifecycle.
- `completeEvent` can coexist with Outstanding Evaluation Obligations.
- Panel membership is intended grouping, not actual Evaluation Occurrence participation.
- actual occurrence participation is not Evaluation Obligation responsibility.
- `EvaluationOccurrence.prepare` creates no obligations.
- ordinary initial obligations are established at occurrence begin for the confirmed starting evaluator set.
- participant adjustment requires an explicit separate responsibility disposition.
- Panel changes never rewrite an already-begun occurrence.
- `completeOccurrence` ends the bounded occurrence; it does not resolve obligations.
- current Team/Division/Alias changes never silently rewrite historical occurrence presentation.
- current MUDAC Evaluation Basis is one exact authoritative Rubric Version.
- Rubric Version supersession never silently rebinds existing occurrences, obligations or Scorecards.
- one Evaluation Obligation maps to at most one logical Scorecard.
- Scorecard Draft state is non-authoritative.
- initial Finalization establishes Scorecard authority + immutable Scorecard Version + meaningful Provenance + obligation satisfaction as one coherent semantic result.
- a Satisfied obligation refers to the logical Scorecard; Versioning identifies its current authoritative Version.
- Judge amendment creates a successor Version of the same logical Scorecard, not another vote/responsibility.
- Versioning/Provenance generic actions are composition-only, not generic MUDAC admin controls.
- paper/electronic/assisted capture preserve the same Judge author, basis and logical Scorecard.
- Organizer capture actor may differ from Judge represented authority but cannot invent judgment or commit intent.
- post-authority transcription mismatch is correction/invalidation work for 011-F.
- **Judging Encounter** references elsewhere are historical pre-split evidence and must be interpreted through Evaluation Occurrence + Evaluation Obligation.
- **Official Outcome Revision** references remain historical evidence for Outcome Declaration.
- runtime retry/idempotency/transaction/queue/session/transport language in old documents is not current Concept Design authority.
