## 011-H external-representation authority now established

Current MUDAC composition preserves:

- exact SourceBasis + purpose + AudienceProfile on each meaningful Export;
- representation authority never promotes source authority;
- Export `Current` / `Affected` / `Stale` / `Superseded` / `Retired` currency remains independent from Publication distribution state;
- existing `validateRepresentation` revalidates Affected Export without changing historical SourceBasis;
- newer/corrected source requires a new Export rather than mutation of the old one;
- Export generation never implies Publication;
- Publication always binds one exact Representation, Audience and Channel;
- source correction never retargets historical Publication;
- withdrawal/supersession preserve the fact that an earlier release occurred;
- official != public != delivered;
- transport/delivery remains downstream realization rather than Publication authority.
