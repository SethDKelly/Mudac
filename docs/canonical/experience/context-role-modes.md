# Canonical contract

The application context stack is:

`Identity → Participation / role mode → Competition → role-specific operational context → current task/artifact`.

Judge and Organizer are explicit modes. Switching mode changes disclosure posture as well as navigation. Navigation never grants authority.

Judge experience centers on event/Panel context, current Encounter, own Scorecard, and own live-event judging history. Organizer experience centers on Preparation, Live Operations, Reconciliation/Outcomes, and Materials/Publication.

Current and historical state must be labeled rather than visually conflated.

See [Access](../concepts/access.md) and [Current vs Historical Truth](../invariants/current-vs-historical-truth.md).
