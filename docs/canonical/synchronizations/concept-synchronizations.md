# Important superseded assumptions

The historical corpus predates the current eighteen-Concept model. In particular, it included semantics that Phase 010/011 later replaced or split, including:

- `Judging Encounter` as a combined occurrence/responsibility boundary;
- Scorecard obligation as non-Concept state;
- `Official Outcome Revision` as the official-outcome mechanism;
- broader runtime-shaped retry/convergence wording than current representation-independent composition authority permits.

Current design instead preserves:

```text
Panel membership
  != Evaluation Occurrence participation
  != Evaluation Obligation responsibility
  != Scorecard evidence
```

and:

```text
Competition Finalization
  != Outcome Declaration
  != Export
  != Publication
  != transport delivery
```
