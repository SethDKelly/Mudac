# Canonical contract

Judge onboarding resolves Competition context, Identity establish/reverification, current Judge Participation, current-event profile/expertise, check-in, Organizer-governed Panel assignment, and derived `Ready to Judge`.

QR, event codes, links, and similar mechanisms accelerate navigation but never grant Identity, Participation, Panel membership, or evaluation authority. A non-camera path is required.

Returning Judges reuse Identity continuity but receive a new current Competition Participation. Expertise is confirmed for the current event and does not create Access.

Ready to Judge is derived from actual source state; it is not manually toggled.

Ordinary onboarding closes at Event Completed except for narrow authorized correction access.
